# 小模型持续工具学习与预算复习：阶段实验报告

更新日期：2026年11月10日  
研究对象：Qwen3-0.6B，连续 QLoRA 微调，File / Database / Python统计函数 / Calendar 四类工具。

## 摘要

本阶段围绕“小模型学习新工具时，如何用有限预算保留旧工具能力”展开，完成了连续学习基线、阶段能力补评、三种复习策略对照和监测信号分析。历史补评表明，在两种学习顺序下，后续工具学习使旧工具联合成功率分别平均下降5.19和4.81个百分点，三个训练种子的变化方向一致。退化在不同任务类型上呈现差异，其中以自然语言描述中位数的任务表现最为集中。

预算复习实验完成了不复习、均匀复习、退化感知复习三组共9个分支。均匀复习在新留出测试上的旧工具联合成功率为55.00%，比不复习高0.74个百分点，新工具成功率均为91.67%。退化感知策略在三个种子中均未检测到中点下降，实际采用了均匀配额。本轮由此建立了复习的参考效果，并把下一阶段的问题具体化为：哪些监测任务能够反映局部退化，以及识别出的退化能否转化为更有价值的复习内容。

后续采用两条相互衔接的实验线：一条研究监测的覆盖、样本量和时机；另一条通过定向复习参考组，直接测量选择复习内容的收益。两条线在相同预算的自适应复习实验中汇合。

## 一、研究目标与已经完成的工作

研究目标是让小模型在持续接触新工具时，兼顾新能力获得、旧能力保留和学习成本。将其分解为三个可以依次回答的问题：旧能力在哪里退化；少量旧数据复习能带来什么效果；根据退化调整复习内容能否进一步提高效率。

| 工作 | 已完成内容 | 对研究的作用 |
|---|---|---|
| 连续工具学习基线 | 四类工具，三种学习顺序，三个种子，共9次完整运行 | 建立学习顺序、能力获得与旧能力变化的观察基础 |
| 阶段补评 | A/C两种顺序，学习前后两个阶段，三个种子，四类工具各30题，共1,440次任务评估 | 在相同评估方式下测量能力变化，保留逐题丢失与获得记录 |
| 独立监测与留出题 | 每类24道监测题、60道留出测试题，共336道 | 将复习决策和最终成绩分开测量，并支持新实例测试 |
| 预算复习对照 | 不复习、均匀复习、退化感知复习，三组×三个种子，9/9完成 | 得到固定复习预算下的策略参考结果 |
| 成对比较流程 | 每个种子共享训练前半段，三组恢复同一个中点状态 | 统一分支起点、前半段学习过程、新样本顺序与复习预算 |
| 监测与成本记录 | 起点、中点、终点监测；输入/输出Token、训练Token和耗时分别记录 | 解释策略何时触发，并测量监测自身的代价 |

A顺序为 File → Database → Python → Calendar；C顺序为 Database → File → Calendar → Python。复习对照采用A顺序最后一个学习阶段，复习预算为新工具训练输入Token的10%。

本报告使用两种主要指标：**答案成功率**衡量最终任务答案是否正确；**联合成功率**要求工具、参数、执行结果和答案均与参考匹配。联合指标提供较严格的调用检查，答案指标同时反映任务结果。统计对象为当前固定工具环境中的实例与措辞任务，各题给出相应工具族的接口。[来源1、2、3]

## 二、主要实验结果

### 1. 连续学习同时伴随能力增长和局部退化

| 观察对象 | 变化 | 研究含义 |
|---|---|---|
| A顺序：学习Calendar之后 | 三个旧工具的联合成功率宏平均下降5.19个百分点 | 后续学习对已有能力产生了可重复的影响 |
| C顺序：学习Python之后 | 对应下降4.81个百分点 | 旧能力退化在另一种学习顺序下也有体现 |
| A顺序的Python答案成功率 | 100% → 91.1% | 原先已经掌握的任务出现部分丢失 |
| C顺序的Calendar答案成功率 | 17.8% → 8.9% | 初始掌握程度和后续保持情况共同决定最终表现 |

这些结果使后续复习目标更具体：对已经掌握的能力研究保持，对初始掌握较弱的能力研究补充学习。二者可以使用不同的数据选择依据。

逐题记录还能区分能力的丢失和获得。例如某个工具的总分变化很小，仍可能包含“几题从正确变错误”和“另外几题从错误变正确”。因此，本项目已经具备从总分进入具体退化类型的分析基础。[来源2]

### 2. 小额复习获得了参考效果，自适应分配的作用取决于监测信号

以下为新留出测试上的三个种子均值。旧工具成绩按三个工具等权平均。

| 方法 | 旧工具联合成功率 | 旧工具答案成功率 | 新工具联合成功率 | 相比不复习的旧工具联合增益 |
|---|---:|---:|---:|---:|
| 不复习 | 54.26% | 61.85% | 91.67% | — |
| 均匀复习 | 55.00% | 62.59% | 91.67% | +0.74个百分点 |
| 退化感知复习 | 54.63% | 62.04% | 91.67% | +0.37个百分点 |

均匀复习在两个种子上各提高约1.11个百分点，在另一个种子上与不复习持平。本轮观察到的收益较小，新工具成绩保持一致。这为后续方法提供了一个清晰的成本与效果参照。

在这套新留出题上，不复习组的旧工具联合成功率从52.22%上升至54.26%，总体呈现净改善。历史补评和本轮复习对照由此揭示了两种表现：部分既有题型发生退化，新留出任务的平均表现则可以改善。下一轮将同时追踪总分和原先答对题目的丢失，测量局部能力保持。

退化感知策略在三个种子中均未检测到中点下降，触发次数为0/3。它随后执行均匀配额，实际旧样本和插入安排与均匀组相同。因此，本轮得到的是自适应系统在无下降信号时的运行表现；针对性分配的收益需要在出现有效信号的条件下测量。两组之间的小幅成绩差异不归因于分配策略。[来源3]

### 3. 退化具有任务类型差异，表述与工具选择之间的联系值得研究

历史补评中，中位数自然表述任务 `stats_median_prose` 的联合成功率在三个种子中分别由100%降至40%、20%和60%，每个种子评估5道该类型任务。当前Python监测题在开始、中点和结束均为100%。

两类任务有一个具体区别：监测题明确要求计算“median”，历史任务则以“middle value”等自然表述提出问题。这个差异提供了一个可检验的研究假设：**持续学习可能改变模型从任务表述识别所需工具的能力，而直接点名操作的题目仍能正常完成。**

下一步将通过相同数值实例的成对问法来测量这一关系。同时，把历史题和监测题交叉用于同一批模型，以分开训练轨迹和题目覆盖的影响。任务类型名称是否相同作为描述信息，具体覆盖效果由交叉评估和成对任务的表现判断。[来源4]

### 4. 监测成本已成为可以直接优化的研究变量

| 成本项目 | 本轮每个分支完整流程的平均参考值 |
|---|---:|
| 新工具训练输入Token | 74,944 |
| 复习输入Token（复习组） | 约7,491 |
| 监测输入Token | 约84,826 |
| 监测输出Token | 约9,247 |
| 监测耗时 | 约120.9秒 |
| 无复习流程中的训练耗时 | 约109.9秒 |

监测在本机的耗时已与这段训练相近，减少监测题量、调整检查频率和选择更有信息量的任务具有直接价值。第二版复用了共同前半段，因此部分分支没有再次执行监测；上表反映完整流程的参考成本。推理和训练Token分别计量，实际实验耗时另行记录。部署均匀复习或不复习时，可以省去自适应监测模块。[来源3]

## 三、下一阶段的研究方向

后续主线确定为：**任务类型感知的监测与预算复习**。重点是把“看见哪些能力退化”与“复习哪些内容有效”连接起来。

### 方向一：让监测任务对应实际能力变化

先复用已有模型完成两个小实验，获得监测设计的直接依据。

**实验A：同一模型、两套试卷的交叉评估。**

| 训练后的模型 | 历史测试题 | 当前监测题 |
|---|---|---|
| 历史A顺序的最终模型 | 已有结果 | 补测 |
| 第二版不复习的最终模型 | 补测 | 已有结果 |

三个种子、三个旧工具共补约486次任务评估，无需重新训练。统一模型加载和推理方式，必要时补齐同口径的起点评估。输出每个模型在两套任务上的变化矩阵：如果同一模型在历史题上下降而监测题上保持，优先改善监测覆盖；如果退化主要集中在某条学习轨迹，则将该学习条件纳入下一轮复习比较。

**实验B：先围绕中位数构造24组成对任务。**

每组使用相同数值，分别采用直接点名操作和自然任务描述两种表达。保持原有实验语言，并用无歧义的奇数长度列表明确“排序后正中位置”的含义。在开始、中点、结束三个状态、三个种子上评估，共432次任务评估。分别记录工具选择、参数和答案，观察表述差距出现在哪个环节、何时扩大。

中位数实验给出清晰信号后，再扩展到文件最后匹配行和数据库条件排序任务，形成少量但覆盖关键退化类型的监测题。

**样本规模作为一个单独可测的因素。** 对已确定的关键任务类型，可将监测池扩为96个独立实例，再从同一池中抽取12、24、48和96题比较检出稳定性。保持题型比例不变，使题量变化与覆盖变化分开。较大题池作为参考估计；最终测试仍使用独立实例。

这一方向的产物是：一套能反映已观察退化、并能说明题量与成本关系的监测集。

### 方向二：测量选对复习内容的收益，并连接自动分配

监测设计可以与一个简单的定向复习实验并行推进。加入“固定定向复习”参考组，根据独立开发诊断确定重点任务类型，直接测量复习内容选择的价值。

| 方法 | 配额与内容选择 | 要回答的问题 |
|---|---|---|
| 不复习 | 继续学习新工具 | 这一学习条件下的自然变化是什么？ |
| 均匀复习 | 旧工具等Token配额，族内随机抽样 | 普通复习提供多少收益？ |
| 固定定向复习 | 根据独立诊断预先确定重点类型，保留均匀覆盖 | 已知重点后，复习内容选择能带来多少收益？ |
| 在线自适应复习 | 在共同决策点读取改进后的监测信号，再分配配额 | 在线监测能否获得接近定向参考组的收益？ |

建议保留Qwen3-0.6B、三个种子和10%复习预算，使用共享中点，形成4组×3个种子的12次单阶段续训。复习样本从相同的旧训练池选取，定向目标在训练分支开始前由开发诊断确定；下一轮最终评价使用独立新实例。

首轮可固定一个简单配额规则：定向组和自适应组均将50%的复习Token均匀覆盖旧工具，另外50%分配给重点任务类型。前者的重点来自预先冻结的开发诊断，后者来自中点监测；未发现下降时回到均匀分配。统一配额规则后，两组的差别主要落在重点内容如何确定。

评价同时覆盖旧能力保持、新工具学习、针对性分配是否实际发生，以及监测与复习成本。结果将直接决定方法如何迭代：

- 固定定向组优于均匀组，而自适应组接近均匀组：继续提高监测与分配的对齐程度。
- 自适应组接近定向参考组：进入监测压缩、预算效率和跨顺序验证。
- 定向与均匀组收益接近：检查旧训练池是否含有足以恢复目标能力的例子，或能力本身是否需要更多有效训练。

固定定向组是一种有诊断信息的参考策略。它帮助测量内容选择的潜力，与在线自适应组共同完成对“检测”和“复习”两个环节的分析。

### 方向三：适度扩大干扰条件，建立成本与效果关系

实验规模的扩展围绕明确的问题进行：

| 扩展变量 | 建议设置 | 研究目的 |
|---|---|---|
| 新工具学习强度 | 2与4个epoch，所有方法使用相同曝光条件 | 比较轻微与较强学习干扰下的复习需求 |
| 监测位置 | 先用开始/50%/结束；有晚期退化时加入75% | 确定何时检查更有价值 |
| 监测题量 | 12/24/48/96，固定题型比例 | 测量检出稳定性与监测成本的关系 |
| 复习预算 | 5%/10%/20% | 描绘旧能力保持与额外训练量的关系 |
| 学习顺序 | A上的规则固定后，增加C或另一预定顺序 | 检验不同能力获得水平和干扰关系下的表现 |

这些变量分轮考察，不组合成一次完整的大规模扫描。优先完成监测与内容选择两条主线；根据结果挑选最有信息量的扩展变量。学习强度的各个预定条件都保留结果，以呈现方法在哪些场景下需要复习、在哪些场景下可以节省预算。

第一批复用现有模型，能够较快给出第二批的题型与场景依据。第二批直接产生方法比较结果。第三批将有效设置扩展为更稳定、更节省的方案。

## 五、阶段结论

本项目已经完成了从研究想法到可运行实验体系的转化，并在小模型连续工具学习中观察到了重复出现的旧能力退化。预算复习实验给出了均匀复习的参考效果，监测分析进一步暴露出工具整体表现、局部任务类型与任务表述之间的差异。

当前最有价值的推进方向，是把这些差异转化为可操作的复习决策：用少量有代表性的任务发现退化，通过同预算的定向复习检验恢复收益，再让在线监测自动完成内容选择。后续实验将围绕这一条主线积累证据。
