## 4. 对监测与复习的直接含义

1. **A 的下降在中点已可见**：如果监测题覆盖历史题中的退化类型，50% 检查点就足够；不需要先补 75%。
2. **probe 的低分不是“能力保留好”**：同一模型在历史题上下降、在 probe 上上升；必须把 test-like 模板和间接措辞加入监测。
3. **中位数自然表述的主要失败是工具选择，但只在 end 明显，且高度 seed 依赖**；它不能单独代表全部旧能力退化。
4. **C 的 Database 在 stage1→2 就掉 20pp**；监测集必须包含 database 条件/排序类任务，不能只围绕中位数。
5. 下一步优先做 two-suite 的 test-like 监测题（median、file last match、db filter top 等）和 start/midpoint/end 验证，再进入定向复习参考组；不要直接扩大 replay 预算。
