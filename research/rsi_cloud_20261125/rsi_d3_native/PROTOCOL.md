# Terminal-width admission: paired actions versus native contract

Frozen before running. Actual published wheels wcwidth 0.2.14 (legacy deployment) and 0.3.0 (new deployment, adds documented ambiguous_width). Benign formatting task: pad each of two text labels to the same fixed-width terminal grid, possibly rendered under different declared ambiguous character widths. Use fixtures consisting only of ASCII and the pre-registered ambiguous characters U+00B7, U+03A9, U+00A1; independent expected padding from ASCII width one and the terminal profile's explicit width for one ambiguous character. Not a historical regression count or measurement of real terminal rendering.

Actions: A accepts the newer API default (narrow) for both labels; B returns to a legacy deployment with its existing wide compatibility adapter for both labels; N uses the newer documented ambiguous_width argument independently per declared label. B adds a cell per known ambiguous fixture character to the old width result. Compare also native schema planning under the legacy A/B-only routing constraint: for distinct width preferences and two ambiguous labels, abstain; otherwise dispatch to a plausible matching A/B (ASCII labels impose no width requirement). All expose the same label strings and profile, no secret ground-truth leak. A/B-only marginal and joint logging are aggregate-information analyses; they intentionally ignore available profile semantics, and therefore do not establish field non-identifiability under full metadata.

Construct two worlds by fixed fixtures: complementary A/B actions (half ambiguous labels all-narrow, half all-wide); overlapping A/B actions (half ASCII-only, half both labels ambiguous with opposing widths). Twelve templates per subgroup, 24 reports per world. Independent oracle compares exact padding count for both fields, not equality to action N. Whether a report is delivered correctly and both fields' actual widths are measured separately. Costs in arbitrary units: incorrect delivery 1; abstention 0.35; unit actuation common cost omitted; two mandatory complete shadow audits charge 0.35 total; sequential audit of one action at a time charges 0.175 each and stops if A passes (try B otherwise). Positive audited artifacts are reused as deliveries with no rerun. Counts report audit executions and additional live executions separately. Full factorial execution is a measurement workload, not free deployment feedback.

Show whether A/B paired outcomes reverse preference between audit and fixed action under flat/bundled cost, under short-circuit cost, and whether strict benefit against the native per-field contract survives. If native implements the task correctly at no extra verification, do not advance this as algorithmic evidence.
