# N0：从终值一致、回调不同的异常反推机制

attrs 25.3.0→25.4.0 的已知公开问题。显式传入 200 时，旧版回调收到 100、新版收到 200；两版对象的最终值都是 200。用回调收到显式构造值作为独立判据。[attrs 官方历史记录（#1427）](https://www.attrs.org/en/stable/changelog.html)。

| 检验 | 1 个配对输入 | 8 个配对输入 | 64 个配对输入 |
|:--|--:|--:|--:|
| 固定最终产物观察、只增加输入 | 0 | 0 | 0 |
| 改读回调参数、做精确判定 | 1 | 8 | 64 |
| 读同一回调，但只比较数值符号 | 0 | 0 | 0 |
| 原生直接挂钩并精确判定 | 1 | 8 | 64 |

表为该已知缺陷下可区分的输入变体数，**不是独立缺陷数**。额外输入相同于默认值，两端均无差异；固定版无误判。符号对照刻意粗化判据，只说明判据也是可单独干预的因素，不说明真实模型以此判断。本轮支持这个受控池的瓶颈是公开观察接口没有纳入策略；已经知道用哪一个接口时，原生基线达到上界，因此不声称新算法。

**可检验机制。** 如果两个实现对所有允许测试历史和输入的可见响应都相同，则自适应选择输入的策略也会看到同分布的交互轨迹，更多同类查询不能区分它们。证明是对相同随机种子下的查询历史归纳。实验只覆盖冻结输入池及指定投影，不能把有限样本相等外推成全称结论。算法立项需要独立案例证明：存在可行观察组合，但同信息、同预算的原生或精确强基线仍不能解决，而不是把已知回调重新命名。

复现（Python 3.12；Linux x86-64）。
```sh
mkdir -p wheels releases
for ver in 25.3.0 25.4.0; do
  python -m pip download --no-deps --only-binary=:all: -d wheels attrs==$ver
  python -m zipfile -e wheels/attrs-$ver-py3-none-any.whl releases/attrs-$ver
done
sha256sum -c LOCK.sha256
python -B run.py releases | diff -u aggregate.json -
```
