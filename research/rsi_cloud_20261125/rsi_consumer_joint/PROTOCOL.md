# Joint observer pilot, sealed before execution

Actual public APIs, development mechanism screen (not historical defect, no security). Endpoint-equivalent paths on two benign consumers: SQLite record refresh (in-place UPDATE versus replacement allocated a different rowid) and ElementTree text refresh (mutate reference versus replace the element with a fresh copy). Contracts: a live downstream reference attached before refresh must still denote that same record/element after refresh. Compare byte-equal endpoint business data and an independent identity-continuity oracle based on whether a path is specified to preserve reference. Distinguish designed aliases, not all practical repairs.

Balanced block: path preserve with original label A and B, path replace with original A and B. Expected labels are preserve, preserve, invalidates, invalidates; swap labels on replacement. Each position's distribution is matched exactly by design; full observer values are not sent to the planner for free at deployment. Available observations: before/after opaque handle, before/after serialized value, stable key, revision context. Candidate grammar is all pairs of legally comparable readings plus no-op and one-read raw classifiers. Both algorithms discover which pair and polarity using the same 12 development blocks (48 cases) per domain. Freeze search before held-out evaluation; 12 disjoint blocks per domain, with new opaque identities/labels. Do not fix the relevant observation in the chooser. Holdouts grouped by block, not independent bugs.

Compare typed pair consistency and exact shortest-subset enumerator offering all possible one/two-point observations and identical hypothesis language (same-type equality/inequality and one-point finite-table with majority fallback). Budget 2 readings, count distinct readings incl. both if comparing; compare every singleton as a separate descriptive upper bound on development plus held-out audit. Report development winner, train/heldout accuracy, minimum achievable budget under this language and full-observation costs. Do not claim innovation if exact comparator obtains same outcome and call cost.
