# H1: safe local progress while report preferences are unknown

Frozen before execution. Generate a local CSV grade-band-style summary from synthetic normalized score records only. Two unknowns: exclude incomplete records or count them as zero, and one-decimal tie rule (half-up or half-even). Real CSV parsing and serialization, real Decimal arithmetic. Nothing is published or sent; "early artifact" means built locally. Correctness oracle uses independent exact-integer rounding and CSV row verification, not expected files from the tested program.

Compare wait; eager default with private rework (early bytes may be wrong, never sent); shared static dependency DAG with parse+group checkpoint; candidate compile a receipt from all four choices' sufficient-statistic report projections and stage early bytes only if every projection agrees; stronger guarded native DAG directly checks observed incomplete count and exact half-even-vs-up tie condition, using same data, and stages the same early output when proved invariant. All policies may run up to five pre-answer stages; each stage costs one accounting unit (read, group, projection/receipt/guard, write). Candidate receipt charged one pass over group rows but reports all 4 projection calculations in it. No wall-clock equivalence implied; no assumed user wait or external scheduling.

Fixture families: complete invariant, complete rounding-sensitive, incompleteness-sensitive, and a group with no completed records. Freeze first answer-independent safe prefix and independently evaluate all four documented choices on both development (8 fixture IDs per family) and held-out shapes (10 new fixture IDs per family with new categories/scores). A report is deemed safe early iff actual bytes pass every legal completion. Compare total stages, post-answer stages, rework, bad final artifacts, number of safely staged reports, and separate arithmetic projection work. Scope to finite known choices and no revisions to the source file. Test admits a candidate only if it advances safe work versus a strong same-information guarded DAG at no higher overall work. A tie is a useful operational conclusion, not a new algorithm.
