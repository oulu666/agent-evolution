# F1 executable admission screen: the informational content of paired repair labels

Frozen before simulation. No LLM, fine-tuning, embeddings, tokenization or real model evidence. Use real functional Python Decimal quantization and SQLite window ranking, with known finite hypothetical app contracts. On every fixture, enumerate real action outputs. Hidden contract (uniform over mode and, for partial feedback, one business output projection) determines the accepted artifact set. Exact mode checks entire report. Partial mode checks one persistent but undeclared output field. Both form controlled synthetic tasks. All algorithms get identical action-output semantics and a priori contract vocabulary; there is no learning from the held-out label.

Randomized, blocked by 24 seeds per API and regime; hold outcome ruler fixed within each seed. The same two successful anchors and the same budget of four feedback records per arm. Paired gets each anchor plus a failing alternative on that same input. Broken pair swaps the two failed alternatives' input bindings, preserving their labels, action marginals and record budget. Random success-only fills the other two records with valid examples from two other development inputs. Matched strong success-only gets, in addition to those anchors, the two valid development records (excluding anchor fixtures) that most constrain the remaining exact hypothesis set. This latter feedback producer is privileged and pays off-line curation/scoring; it exposes an optimistic bound, not an equally cheap algorithm. Feedback records have same finite fields and fixed width (5 ASCII bytes each, 20 total). No LLM tokenizer parity claimed. Data logging is four shown experimental results, not 4 calls for curating or drawing only positive/negative trials; constructing the truth/artifact tables costs explicit exhaustive library executions reported separately.

Exact version-space inference on all arms, with uniform compatible hypothesis weighting. Reject contradictory feedback (abstain), and choose a held-out action maximizing conditional acceptance; abstain if no majority. Also replay modal successful action unchanged as copy control. Score distinct development vs held-out input ranges and max array size. Report held-out correct, wrong, abstain, and correct when none of the representative-mask success actions from exposure would be right (no copying witness). Training contracts persist; task shape changes, modules don't. Compare exact-feedback theorem: given a positive repair on x accompanied by known full outcome, a negative sibling label on x is logically implied; pairing may matter for partial feedback but only if the negative excludes a contract still consistent with the success.
