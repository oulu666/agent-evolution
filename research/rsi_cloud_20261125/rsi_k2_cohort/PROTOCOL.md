Scope frozen in SEARCH.md. All three use small, valid locally-generated input; never open external or malformed samples. Twelve witness variants (first/second six separately) plus four no-change controls each. Pillow: owned palette layers encode and reload APNG frame 2 with an ordinary transparent overlay; independent raster oracle selects prior pixel at transparent idx0 and front color otherwise. Native old-workaround uses public Image.convert("RGBA") prior to writing, same original layers. The task is production-and-reading of privately owned layers, not recovering already corrupted output from external sources. Click: public HelpFormatter with short fixed-width command names and empty or ordinary arguments; expected Usage line computed algebraically; old native uses public write of the header when args are empty. wcwidth: first screen modern NFD syllable Hangul against fixed width 2 under the 0.2.9/0.2.14 endpoints; if both conform and the changelog has no fixed affected code point, move to tightly documented U+00AD. For soft hyphen choose ASCII and known full-width CJK forms only, per-codepoint display convention based on upstream width rule; native old adapts just U+00AD. This is an application terminal-width contract, not a claim about observed fonts. Use isolated subprocesses and verify imported module paths and versions. Do not claim all active releases regress or modern API unsafe.
