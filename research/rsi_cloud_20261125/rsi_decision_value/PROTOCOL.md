# D1: can repair outcomes teach when verification is worth a call?

Controlled admission test, not a benchmark of historical bugs. We apply real Python/NumPy numerical operations to synthetic tasks with frozen reference semantics. Each case proposes one compatibility adapter; the actions are accept, undo and use a known-correct fallback, or execute one canary and fall back on failure. Fallback cost is 2 or 3, verification adds 0.75 or 1.25 and a bad delivery costs 8 by default. Costs are assumed units, not timings. A verification pass can miss an error.

Use leave-one-API-family-out, not random replicate holdout, over decimal rounding, NumPy integer rounding, Python datetime calendar addition and statistics aggregation. Before choosing, every method gets native candidate previews on four inputs plus the representative canary's nominal coverage estimated by a generic cost-free domain description; no canary result or final test result. Each learns from the same counterfactual training labels. The proposed structured model estimates wrong-delivery rate and conditional canary detection; compare to direct cost regression, joint outcome regression, confidence plus unconditional catch rate, an explicit native-policy rule, and always-verify/undo. Use ridge with fixed an a priori constant and clip probabilities. Report primary cost and unsafe count, action distributions and penalty sensitivity 4/8/16. Counterfactual clairvoyant cost is only a lower bound.

The go rule is strictly lower loss than every deployable comparator in at least 3 of 4 independent API families at default penalty, with no aggregate increase in wrong delivery relative to the best deployable comparator. This one controlled setup cannot qualify an algorithm by itself. Stop if a strong baseline matches or if family transfer is unstable. Synthetic scenarios share within-family templates; do not report replicate-level significance. This is not LLM fine-tuning.

Closest framing: Mozannar & Sontag, ICML 2020, [Consistent Estimators for Learning to Defer to an Expert](https://proceedings.mlr.press/v119/mozannar20b.html). Here the deferred option is a fallible assay plus a deterministic fallback, so generic confidence thresholds need not rank its value correctly; joint calibration remains a strong non-novel comparator.
