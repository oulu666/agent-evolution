# 残差结构投票：对不可直接写入的报表反推修复组合

候选：把开关的独立效应从完整查询的三个数值中扣掉。利用剩余的带符号残差识别哪些修复需要联合应用。对能解释所有已观测残差的单项、双项相互作用假设投票，优先实际执行最多假设认为能满足所有目标的组合；不存在合适解释时回退到二次岭模型。数值输出只用于选下一个候选；实际 SQLite 读回与目标完全相等才交付。

应用场景限制：报表是由数据查询产生的派生值，只能通过受支持的源输入开关复现。直接改输出并不是可复现的交付。本轮来源数据和相互作用由实验控制，不能代表这种限制在真实迁移中的流行程度。三个字段均为合成数据；诊断信息和已完成的精确检查相同，不评估未知规范导致的误交付。7 个二元开关，查询 128 个候选中的至多 12 个；其中前 8 个是共享的零配置与单开关校准。

## 证据

第一阶段两批各 96 个，精确残差投票对共享相同数值、二阶特征的岭基线为 66 vs 60、69 vs 61，总计 135 vs 121。全体配对改善 14、退步 0；Exact McNemar 未校正 p=0.000122，仅是对本生成器样本的描述。分解为纯加性 48 vs 48、两个相互作用 36 vs 30、密集 20 vs 18、包含三阶 31 vs 25。

预冻结的新种子补测 72 个，扩展对照结果：

| 策略 | 正确完成 | 共计查询 |
|---|---:|---:|
| 残差结构投票 | 54/72 | 725 |
| 多任务 L1 | 53/72 | 728 |
| 同信息二阶岭 | 47/72 | 732 |
| Hamming 核高斯过程 | 46/72 | 735 |
| 显式做一次配对探测后转岭 | 47/72 | 739 |

对最强的多任务 L1，逐题 2 胜、1 负，其余一致。在密集情形还反向落后 1 个。**没有证据证明投票机制能稳定超越标准稀疏拟合**。作为可复现负结果归档，不作为算法主线晋级。

[BOCS](https://proceedings.mlr.press/v80/baptista18a.html) 已研究用稀疏结构做黑盒组合优化，[COMBO](https://proceedings.neurips.cc/paper_files/paper/2019/hash/2cb6b10338a7fc4117a80da24b582060-Abstract.html) 使用图结构核。[Learning Fourier Sparse Set Functions](https://proceedings.mlr.press/v22/stobbe12.html) 则给稀疏集合函数恢复理论。这里的专门化是利用完整的多个精确输出及单次和组合作用的反例一致性，并不构成“首创稀疏组合优化”的论据；原型没有复现完整的 BOCS/COMBO。它穷举至多两个配对假设并枚举 128 个完整候选，复杂度不能外推到数百个开关。
