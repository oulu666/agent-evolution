# 接受、回滚、验证：边际反馈不能识别验证价值

真实 openpyxl 建立、写出、重读 XLSX 账单，观测先只收集单元格数值与字体；验收另验读取货币数字格式。考察两种受控耦合，每种 16 个校准和 16 个测试产物对：A 是编辑后的交付是否正确，R 是回滚后交付是否正确。世界 1 中 A=R；世界 2 中 A=1−R；两个世界各有一半编辑正确、也各有一半回滚正确。被动仅接受的日志完全相同；允许一批任务执行接受、一批执行回滚，假设只能得到无序单动作日志，其内容也完全相同。这是人为构造的有限不可识别例，**不是历史故障、实际用户花费或算法原创性**。

| 实际平均决策成本 | 编辑与回滚同成同败 | 编辑与回滚互补 |
|---|---:|---:|
| 直接接受 | 0.500 | 0.500 |
| 直接回滚 | 0.500 | 0.500 |
| 验证两份后优先交付任一正确产物 | 0.525 | 0.350 |

错误交付成本 1、验证 0.35、无产物可交付时暂缓 0.35，均是冻结的人为单位。验证成本公式为 (c_v+c_{defer}P(A=0,R=0))。边际正确率只能给出二者皆错概率的 Fréchet 区间 [0,0.5]；用独立性假设或最坏界并不能识别真实联合。独立性选验两份，在冗余世界额外付出 0.025；最坏界选直接接受，在互补世界损失 0.15。若对两种世界赋相同权重，无信息的平均最优固定策略成本是 (0.525+0.350)/2=0.4375；成对数据能按世界选方案，平均 (0.500+0.350)/2=0.425。在所比较的三种日志记录方式里，只有成对实测在两个世界各自选对。如果允许随机化，接受概率设为 1/7 可把最坏后悔降到约 0.02143，但仍非零。结论不排斥真实任务中借更丰富的日志、结构假设或直接验证行动结果打破歧义；若可直接观察验证策略产生的损失，也可记录它的结果。

附加同调用总数检查（非初始协议）：16 个单动作检查无法识别，两份各 8 个产物对的成对批次同样消耗 16 个检查，均能识别，体现配对而非纯检查数量在本确定性例子中的作用。这样不保证随机、小样本或心智模型漂移条件下的误差。所有工作簿均在内存生成，不涉及用户文件。
