# J2: trained closed-loop recovery after a missing SQLite receipt

Frozen before execution. Actual in-memory SQLite commits/retries/probes; synthetic lost-receipt behaviors in a benign work-order append. User contract: exactly one durable row for intended operation, or explicitly defer rather than falsely confirm. Earlier telemetry is prepared, durable, or opaque. A trusted prepared/durable event deterministically indicates no commit/commit. Untrusted telemetry and opaque events do not determine whether the first independent transaction committed. The learner sees telemetry and public trust/idempotency capability, not actual initial row count. A probe reads the durable count, consuming one of at most two recovery steps. A plain retry may duplicate; optional idempotent retry atomically inserts only if missing. All policies have same calls and actions. Shared initial lost receipt is outside recovery budget.

Frozen costs (assumed units, not timings): probe .14, regular retry .22, idempotent retry .26, defer .45, wrong confirmation 3. All successful writes (even duplicates) are made against isolated synthetic SQLite. Report duplicate rows, false confirmations, deferrals and total cost. No external actions. An exact clairvoyant lower bound can see initial committed state, has same actions, is not deployable. Compare two strong native policies: robust idempotent/transaction semantics with exact status when available, and an expected-cost native planner that assumes source ambiguity probability 0.5 when choosing between idempotent retry and probe. Neither sees held-out probabilities.

Train tabular fitted Q at two steps from 6000 shared stochastic exploration episodes on CPU, with terminal reward and per-step costs identical across feature ablations: full history, no prior telemetry, and training telemetry shuffled within trust/idempotency strata. Shuffle affects episode observation labels only, never SQL state or reward. Fitted Q learns backward from all sampled actions and uses a fixed conservative fallback for no support. Evaluate deterministic closed-loop decisions on separately seeded 360-case panels with ambiguous first-commit probability 0.5, 0.8, or 0.2 (not given to policy). Model-free tabular policy only, not fine-tuning or language-model evidence. Admit only if it safely improves on both native controls in held-out conditions; otherwise preserve telemetry signal and stop. Exact functional checks use independent row counts for the final artifact.
