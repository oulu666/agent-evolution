# Consumer continuation feasibility, version 1

Development screen, not blind. Compare actual attrs 25.3.0 and 25.4.0 (`__attrs_pre_init__` argument forwarding in #1427), plus actual CPython decimal arithmetic (different computation paths, not version differences). No security behavior. All probes use only public APIs. A consumer is either installed in a documented lifecycle hook before execution, or observes documented context flags after the result; no internal state inspection.

Each family includes 16 positive and 8 negative-control fixtures. Endpoint definition: complete serialized constructed attrs field dict, or exact Decimal tuple. Each fixture prescribes source event and a business rule. attrs: reserve a record only if the supplied estimate clears a given threshold; the consumer must use the constructor request, not eventual normalized object. Decimal: review an amount only if the operation discarded a nonzero digit; the consumer must use arithmetic evidence, not formatted amount. Verify this independent semantic contract against observed routes. Positive if endpoints match and the candidate consumer disagrees between paths with the reference path conforming to the known business rule. On a control both paths should yield the reference business output; no difference with conformant reference is predicted.

Type-directed composition connects the task-required evidence type to a legal public source, then validates the appended consumer. Strong native baseline directly connects the documented callback / signal to a business decision. Matched exhaustive oracle evaluates all three possible public sources (endpoint, after-state, and lifecycle/arithmetic evidence); fixed endpoint continuation tries two of them. Main online budget two paired probes, early stop on positive. Exhaustive counts call on all three even if a witness is found. All methods see same candidate APIs and task descriptor. This small panel tests whether composing a legal consumer changes observability, not novelty. If native or exhaustive minimization matches typed composition, do not advance as an algorithm candidate.
