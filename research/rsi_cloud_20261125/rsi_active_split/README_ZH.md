# RSI：主动选择下一条反例

**核心问题：** 第一条反例可以由多种历史特征解释时，寻找下一条能最大程度确认安全修复动作的反例。方法不追求排除最多模型，而追求在探针最不利的可能结果下依然能正确交付多少任务。检验该目标是否超越已有方法。

## 机制与边界

给定剩余的假设集 H、工作负载权重 w(x)，只有当每个 h 都允许动作 a，且旧版也允许 a 时，才自动交付 x；否则暂缓。选择下一探针 q 按可能反馈分裂 H，并首先最大化最坏分支的可交付权重，均值用于打破平分。全体交集计算是可复核的相对证书，不是在未知真实环境中的绝对安全保证；缺失真实假设时可出错。旧版保真不作为免费新增观测，受控 SQLite 面板向各策略提供同样的历史合法动作模型。

对这个有限的一步、固定菜单设定，独立精确枚举也能得到同一最优值：在每个反馈分支里，把每个任务的可行动作枚举一遍，能交付当且仅当有一个动作在全部剩余模型都可用；然后最坏分支取最小，在全部思路里取最大。这等价于本方法使用的目标。因而在同信息、同约束下没有改善空间，不应把重写目标函数等同新算法。[Decision Region Determination，含 HEC 主动学习](https://proceedings.mlr.press/v33/javdani14.html) 是直接相关工作；本原型不是 HEC 的完整复现。

## 第一部分：受控 SQLite 面板

80 个生成面板、每个八种潜在实际状态，共 640 个回放情形。真实 SQLite 运行回滚和检查，观察掩码相同的执行有缓存；全策略共同使用已知假设表。一个完整探针包含对三个恢复动作的独立执行。所有策略相同的固定第一条反例以及最多再一条，总计每情形 6 次逻辑动作评估；不是 3,840 次无缓存物理调用。下表 10,240 是任务带权总数，不能当成独立缺陷或样本。最弱项是每个面板取八个真世界中最弱一次加总。

| 策略 | 正确交付权重 / 10,240 | 最弱项累计 |
|---|---:|---:|
| 固定下一反例 | 8,403 | 894 |
| 最大信息熵 | 8,858 | 985 |
| 精确 Bayes 期望覆盖 | 8,866 | 986 |
| 本方法最坏安全覆盖 | 8,871 | 987 |
| 独立精确极小极大 | 8,871 | 987 |

独立精确法与本方法在全部 640 个情形选同一探针，交付相同。提升高度依赖有偏部署权重一组；无信号组没有改善，全部动作可等价的控制组已经全交付。全部观测零错误，因为真实世界由已知模型库生成，又只批准全体同意的动作。不能据此推断模型之外的安全性。

## 第二部分：真实 pandas 行为压力测试

使用前轮 pandas 2.2.3 → 3.0.0 Copy-on-Write 的实际双版本程序。在不知道四个历史特征中哪个与兼容修复有关的设定下，四个解释都与第一条反例一致。16 个输入条件各用四组数值真实执行；24 种特征排序重放同一矩阵，盲于哪个列叫创建来源。比较同样信息、同样第二条反例预算。

| 策略 | 双版均正确 / 1,536 | 错误 | 暂缓 |
|---|---:|---:|---:|
| 先测排序里的第一个字段 | 672 | 0 | 864 |
| 信息熵 | 768 | 0 | 768 |
| Bayes | 768 | 0 | 768 |
| 最坏安全覆盖 | 768 | 0 | 768 |
| 已知来源的专家单项对照 | 1,536 | 0 | 0 |
| 执行前多读一次内存共享状态 | 1,536 | 0 | 0 |

一条附加反例的标签只有两种，而四个解释在某些工作负载任务上两两不同，所以不可能保证每个真值分支都能完整区分（程序穷举重核）。再允许一条附加反例，用两个二元查询定位四种解释，在同一真实回放上达到 **1,536/1,536**。这验证证据数量约束，不是改权重可突破的算法优势，且强工程对照仍可同时全对。

## 研究判断

不把本轮方法立为核心创新。把“看起来有两种动作”与“完整反馈究竟能有多少种结果”分开作为入组检验。下一步要想突破，测试能否**构造单次返回多种可判定结果的合法探针**，例如一次运行携带多个独立子任务，共享初始化但能分别回读。必须同样允许强对照批处理，并同时计入子任务数、完整工具调用和实际时间，排除单纯换计费单位。只有真实系统确有接口支持、两条独立证据不能由简单原生诊断获取，才值得继续。

复现：Python 3.12；本目录 `python pilot.py --out results`。pandas 子试验使用同级 `rsi_pandas_split` 的版本准备方法，运行 `python pandas_gate.py --new /path/to/new-release` 和 `python pandas_two.py --new /path/to/new-release`。两个冻结哈希从上一级检验。逐条回放不进入公开仓库。
