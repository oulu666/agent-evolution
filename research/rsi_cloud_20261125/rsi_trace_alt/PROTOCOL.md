# Paired development pilot: composing intermediate document readbacks

Frozen before running the pilot. This is a mechanism screen, not a blind historical-defect or model experiment. We do not access the project's formal holdout.

Each of 240 fixtures has four opaque module IDs for deterministic normalization of Unicode/HTML/URL-encoded text records. Test all policies on each fixture. One labeled calibration document and its desired serialized output are public. A reference order generates that output and eight other independent input documents' reference outputs. Those eight are for scoring a single selected order, not for choosing one. Orders are fixed-length permutations (24 in all). Six complete tool executions, four primitive invocations per execution, at most. Every policy obtains exactly the same kind of readback: the intermediate full document at every step. All must physically confirm any selected order on calibration. A policy stops at its first passing order.

Hypothesis: in fixed-budget exploration, scheduling orders with both a long recorded prefix and a reverse-indexed suffix ending at the goal recovers more useful orders than selecting by forward trace evidence alone. Infer edges only from exact, whole-document equality, and never assume edits commute or are invertible. Check reverse and forward full-path certificates coincide on every candidate scored. Shared warm start and deterministic shuffled candidate tie breaks. Controls: shuffled search; forward scheduler (first prefer a certified goal path, otherwise the fewest unresolved transitions beyond known prefix); two-ended scheduler (same certificate, then fewest unresolved transitions between known prefix and goal-reaching suffix). Both exclude certified misses. Policies do not see module meanings, reference order or sealed outputs.

Primary: solved on calibration AND all eight unseen documents. Secondary: calibration hits; selected repairs that fail unseen; paired wins/losses versus strongest trace-matched control; total calls. Descriptive paired results only; fixture documents are artificial and overlap in vocabulary. Stop if mechanism does not increase primary success versus the forward control. Do not tune on this run; keep negative results.
