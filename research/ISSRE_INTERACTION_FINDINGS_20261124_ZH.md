## 抽样与冻结

预先选定 attrs 和 python-dateutil 两个新项目，按 2022–2025 年的第一父链、标题与公开模块筛选。attrs 有 14 个符合机械条件的提交，按时间顺序保留最近 6 个，其余 8 个未尝试。dateutil 主层无匹配。仅知此数量时，为空层增加“主分支可达的非合并提交”补充筛选，保持时间、模块和关键词一致，仍无匹配。两项目的测试均在各自老文档版本通过，历史盲测成绩仅来自 attrs。dateutil 使用从 2021 年开始获取的 Git 历史。这是固定检索条件的样本量，不能据此推断项目实际缺陷数量。

测试设计者只使用 attrs 21.4.0 和 python-dateutil 2.8.2 的公开文档。每项目六个任务族，共 48 个基准输入，全部通过文档版本核验。代码、期望、两个候选清单与完整选择计划在揭示前一并记录摘要。单操作者本地冻结，未做第三方托管。源码归档中所载入的 Python 文件均核对对应 Git 对象指纹。[实验协议](ISSRE_INTERACTION_PROTOCOL_20261124_ZH.md) · [冻结摘要](../runs_interaction_blind_20261124/freeze.json) · [attrs 官方文档](https://www.attrs.org/en/21.4.0/api.html) · [dateutil 官方文档](https://dateutil.readthedocs.io/en/2.8.2/relativedelta.html)

## 核心算法

每个任务族事先选定两个有明确预期的条件，生成常规输入 00、两个单条件输入 10 和 01，以及双条件输入 11。例如，属性赋值任务考察是否启用字符串到整数的转换，以及是否启用整数类型校验；冻结字段包括最终值与类型，预期拒绝的输入还检查异常和原值。其他 attrs 任务覆盖私有字段与槽、嵌套与序列化过滤、比较字段与字段值、默认值来源与显式传参、构造时转换与校验。因子由研究者根据文档指定，组合与选择由程序执行。

单条件策略每族执行 10 和 01；组合策略每族保留一个单条件，另一个名额交给 11，按族交替保留 10 或 01；镜像策略将保留顺序翻转。每种主计划正好 12 个公开目标操作。装配逻辑、观察字段和期望规则共用。预算外再分别计算常规输入、所有基础格、全部四格的结果。统计单位为提交对。如果 11 的断言在父提交失败、修复提交通过，同时该族其他三格都没有见证，才有“仅组合输入能暴露差异”的候选，仍须核对上游语义。[实际测试与条件定义](issre_interaction_tasks.py) · [冻结请求清单](../runs_interaction_blind_20261124/plans.json)

## 关键案例：值正确，传递过程出错

attrs 的修复 #1428 涉及初始化前钩子。上游问题记录引用的契约要求钩子收到构造时提供的参数。揭示后，为值默认为 100 的字段注册钩子，同时观察钩子实际收到的值和构造完成后的字段。实验仅改变调用者是否传入 200。[上游问题与语义依据](https://github.com/python-attrs/attrs/issues/1427) · [维护者合入的修复](https://github.com/python-attrs/attrs/pull/1428)

| 调用 | 观察 | 父提交 | 修复提交 |
|---|---|---:|---:|
| 使用默认值 | 最终字段 | 100 | 100 |
| 使用默认值 | 钩子收到的值 | 100 | 100 |
| 显式传入 200 | 最终字段 | 200 | 200 |
| 显式传入 200 | 钩子收到的值 | **100** | **200** |

冻结菜单已有显式传参与默认值的组合；该任务只读最终字段，也没有注册这个钩子。实际见证同时需要具备回调的测试装配和一个能记录回调参数的观察器。它把之前 Rich 的“同时选择输入和渲染字段”推广到一个可重放的生命周期边界案例。该见证使用了揭示后的信息，盲测发现数仍为零。[见证的配对值](../runs_interaction_blind_20261124/findings.json)

## 研究决定

沿用 ISSRE 实证路线。文档覆盖计划和两条件组合已先后出现全菜单零见证。当前数据支持一条具体判断：用有限菜单比较选择策略时，须先报告菜单能显露多少修复，并记录输入类型、运行环境、观察位置及预期依据。对菜单外的修复，提高排序精度无法提高这个菜单的检出上限。这个结论限于冻结菜单和观察范围。

下一轮若继续检验方法，应先从修复前公开的**调用契约**生成“谁向谁传递什么”的断言，例如构造器传给回调的实参、进入与退出时资源的状态。可按修复前已经发布的文档选择版本，由封存程序剥离变更历史和目标身份，减少固定旧文档与候选年份的错配。先在新封存样本上测菜单整体的见证覆盖，再对有见证的样本评价固定预算下的选择。这个设计须保留所有机械入选项以及跨运行时、跨 API 版本的分层记录。已有六个 attrs 提交适合做后续开发样例。

复核时在实验目录副本中保留两份封存清单及冻结文件，依次执行研究目录中的 issre_interaction_run.py run 与 issre_interaction_analysis.py。Python 3.11.9、six 1.17.0、Git、curl 和访问上游提交的网络用于本次重放。源码归档从 GitHub 下载，实验工件在本地保存。上一轮 [输入与观察器盲测报告](ISSRE_BLIND_FINDINGS_20261124_ZH.md) 保留其单独的样本框及冻结哈希。
