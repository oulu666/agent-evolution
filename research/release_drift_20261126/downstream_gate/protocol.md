# 下游验收立项实验 · 2026-11-27

先选消费者及操作，再运行版本对。消费者固定为 MkDocs 1.5.3，自身文档仓库提交 `00b648f0884244a139f034554b59a032113176f6`，沿用原文档、主题、扩展、构建配置及 CI 集成入口。注册的操作是读者从正文点击已发布的站内章节链接，抵达该引用指向的章节。升级前的 `docs/user-guide/writing-your-docs.md` 明确规定生成 HTML 时转换页面路径、保留锚点，并说明标题永久链接的用途。抽样单位为一个下游发布任务与一个依赖转换；没有真实访问日志，不推断读者人数或使用频率。

选择发布时间夹在消费者发布前后的相邻稳定 Markdown 发布 3.4.4（7 月 25 日）和 3.5（10 月 6 日）。消费者发布时间为 9 月 18 日。只读了消费者旧源、该任务的旧文档、CI 与版本发布元数据；未以该依赖的修复清单挑选输入。环境用 CPython 3.11。其余依赖按 2023-09-19 00:00 UTC 截止解析一次，两个环境复用同一个精确清单；仅替换 Markdown wheel。记录版本及包摘要。允许排除环境安装、网络等技术故障并使用同一协议重试，不据结果更换项目或版本。

**原生验收**为消费者原有 `python -m mkdocs.tests.integration`（含两套主题、原有集成项目和严格构建）及构建子系统的原有单元测试。**静态对照一**检查链接目标页面及片段 ID；**静态对照二**重放旧链接，比较命中的标题文本与祖先标题路径。保留基线输入、完整产物和历史引用的使用权限。另报告整页 HTML 字节差异，仅作为变化提示。

主任务面板取默认主题所有页面正文（role=main）中的本站章节引用，排除代码块、生成的标题自链；使用去重的来源页面和旧目标地址计数。允许由站点扩展生成的正文引用，单列与源文本存在同名显式引用的证据强度。以浏览器 URL 规则解析相对地址、站点绝对地址和百分号转义。主配对只纳入旧端能唯一解析到实际标题的引用。同时单列旧端已失效、指向非标题元素或其他排除的引用。对旧链接重放及新端本页是否仍有该引用分别记录。独立用户侧测量使用真实 Chromium 访问由本地 HTTP 提供的构建产物，读取浏览器 `:target`、标题和所在层级。对疑似错误必须追溯原消费者材料，数据不足时记为无法裁定。浏览器选择结果与旧标题发生差异本身不自动算违约。

**立项门槛**为至少一项可复现的真实用户验收错误，修复前已有独立依据，原项目验收及两个便宜的静态对照均未能据此正确处置。静态规则、旧版重放可解释的错误单列。两端都存在的问题不算本次升级引入；环境问题不算算法收益。未达到门槛则保留负结果，无正式封存案例变动。本次不按链接数量计算独立缺陷数。
