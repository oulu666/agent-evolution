# 11 月 26 日云端环境核验

固定抽样框内的 19 个发布版本均在独立 Python 3.11 环境中成功运行。Pillow 7 个版本、pandas 5 个、SciPy 7 个，每版检查 3 个公开操作，共 57 个版本—操作组合。每项使用普通输入与已知预期，例如均匀图像缩放、整数分组求和和无并列秩。此次核验支持在云端执行注册操作。历史漂移数、误报数以及交付收益须由独立配对实验估计。

[GitHub Actions 三项并行作业](https://github.com/oulu666/agent-evolution/actions/runs/45763332235) 使用 Ubuntu 24.04 CPU。各 JSON 保存版本、依赖、下载文件 SHA-256 和抽样框摘要。字段 `process_and_import_ns` 包含独立进程启动、导入与三项检查的总时间，只用于核查环境，不计入正式方法用时。发布前已比对下载工件摘要、运行提交、版本清单和操作清单。
