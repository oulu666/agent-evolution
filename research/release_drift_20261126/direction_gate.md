# 方向判别与主动性归因 · 冻结前登记

2026-11-26 登记。原主比较保留漂移检出与实际错误交付两项指标。新增方向判别作为机理分析。在固定回归已发现变化的案例上也比较两臂的判定与交付，单列这种收益。原“至少两个项目出现主动独有检出”的继续门槛仍按原定义结算，方向判别的改善单独报告。

## 共享信息与强静态对照

同一任务的各臂读取同一份带摘要的资料包，包含注册操作、用户要求及其适用版本、旧 Schema、升级前可用的公开文档、原回归输入和预期、由这些材料导出的候选请求和判据，以及各臂共同可用的备用动作。记录材料版本与出处。各臂都可直接执行已知规范判据。旧输出与契约预期分别保存。策略输入不含历史修复经验、项目入组数、封存材料、升级后的回归测试或标签。每个版本区间的材料独立装载。判据若可廉价直接计算完整任务答案，则直接规范交付也参加比较。

各臂获得完全相同的第 0 步返回和初态快照。固定回归的请求顺序由升级前回归集确定；若总量超预算，另报完整运行。强预排对照允许使用第 0 步信息，使用与主动组相同的生成器、候选集、假设和成本目标，在第一次额外调用前承诺整条请求序列。冻结时从所有合法长度不超过三的序列中按同一注册先验选预期任务损失最小的序列，平局按规范化请求标识排序；若不能完整枚举，记录真实搜索范围与上界缺口。两臂均按同一终止及处置规则消费已获证据。固定回归、预排、随机及主动各自独立复位。主比较使用确定性 CPU 策略，无模型采样；随机对照用 CPython 3.11、种子 20261126、规范化候选顺序，每任务独立从相同种子初始化，运行一次。相同候选序列造成的相关性保留在案例级汇总中。

## 证据如何改变交付

每条判据登记条款、前提、可观察字段、独立预期或关系和适用的用户操作。对新旧两端分别登记“满足／违约／未定”。兼容旧约与遵循新约是不同任务要求，探测前锁定。定位到某操作仍须记录具体被违反的条款；用另一输入构造的微探针只有在冻结的适用关系足以推出目标任务违约时才可支持处置。关系不成立或只是经验相似时保留未定。一次极简输入测试通过，只支持其覆盖的义务。

| 已获证据 | 共同处置 | 评分动作 |
| --- | --- | --- |
| 只有版本差异，目标违约未定 | 额度允许时可继续；结束时交付当前结果 | 登记变化；交付照实评分 |
| 注册用户要求可独立判定，新端满足 | 保留并交付当前结果 | 有旧端违约证据时才记作修复旧错 |
| 有适用于目标任务的新端直接违约见证 | 有独立验证的替代结果就交付，否则暂缓 | 恢复成功须核对最终交付物 |

用户明确要求下的新端判定可以早于旧端归因；旧端证据缺失时保留方向未定字段，不补猜缺失标签。离线 Schema 与判据计算、初态快照复位、离线备用各记次数和时间。第 0 步之后，每次在线询问、重放、验证、旧端对照、在线复位或在线恢复均走同一个计数器。失败调用也扣一次；蜕变比较若需两次在线执行就扣两次。禁止在一次批调用或备用动作里隐藏多次操作。第四次调用在分派前拦截。在预算用尽后，已知目标违约且无已验证替代时按暂缓计入全部任务。

## 替换反馈的归因审计

每步留存资料包与策略摘要、输入历史、上步返回字段及值、收窄或被排除的假设、判别意图、规范化请求或停止动作。冻结正常替代值的来源及可行性条件，不从揭盲结果挑替代值。把全部可能影响处置的分支纳入离线审计。先用原历史重现同一决策，再只替换最近一次返回中注册的字段，固定之前的历史、预算、种子和其余字段。反事实须满足 Schema 和字段间约束。没有可行替代或无法重现时记为不可审核。

* 同一语义请求仅更改解释文字、编号或展示顺序，记作请求不变。请求不变且只因反馈改变处置，计入方向判别。由继续变为停止，单列为节省调用。
* 实际请求发生改变，只能说明该步用到了反馈。还需在同一案例上核对新请求取得的条款见证、静态对照的真实结果、直接规范动作和最终交付，才能归因于主动选问。替换第 0 步返回的效应单列，因为强预排也能使用它。
* 若预排得到同一判定与交付，记为固定输入覆盖即可解释。如预排漏掉且出现有效反馈分支，结论限定于冻结的静态对照。要进一步声称所有固定序列都无法追平，需要跨相同初始可见信息的多个可行分支证明这一点。

## 揭盲计分与冻结签收

按独立变化逐项报告首次发现步骤、条款定位成功数/适用数、两端方向判定（含未定）、正确交付、错误交付、暂缓、恢复及实耗。两个升级端错误机会逐项比较；另外两项由组织者揭盲后按注册任务核实正确方向，单列错误回退数和因此变差的交付数。九项负对照以误判任务违约数/9 报告；纯差异提示单列。逐项记录安全性扣分，不允许其他案例的改善抵消新增错误交付。选问、方向和交付分列；探针次数及多个回答字段均不扩大独立样本数。六项未详审候选和一项待定记录继续封存。本轮只决定是否有值得独立扩容验证的机制。
