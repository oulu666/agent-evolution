# 增量附件：三个合成案例上的成本—正确性曲线

本附件不改写冻结的 `protocol.md`，不改写已记下的 Material 复制与 jq 原始任务及计分，不改写联合学习原实验的分母与发布决策计分，不为归档重跑 `joint-receipt.json` 所记录的对照，不新增第四个合成案例，不勾选 11-30 清单，不打开密封标签，不开展 `question_selection`，不并入 PR #12。工作基于 main [`88ca0d2090794b363c8db82a4106f2c952b69aec`](https://github.com/oulu666/agent-evolution/commit/88ca0d2090794b363c8db82a4106f2c952b69aec)。

## 目的

不再追“联合学习的检测准确率超过所有强基线”。本附件只在现有三个合成案例上，测量有限观察预算下的成本—正确性曲线，验证一个更精确、此前尚未测得的假设：联合学习能否在有限观察预算下，自主选择少量关键证据，达到与完整追踪方法接近或相同的验收质量，并在同等预算下优于最优固定观察策略。

若联合学习只是在得到完整消费轨迹之后才选择正确答案，则没有证明主动选择具有价值。若该假设被强静态方法追平，必须接受负结果，停止继续堆该分支的复杂算法，而不是为保留联合学习制造更复杂的案例。合成结果只属于开发验证。隐藏分页的旧结果只是方法上的逻辑联系，不能当作本假设已被证明。本层不认定为 ESWA 核心算法贡献。

## 方法与计数

同一批三个合成案例、同一任务说明、同一可选观察集 \(\{\texttt{subsequent\_reads},\texttt{contrast\_canaries},\texttt{reread\_known\_slot}\}\) 下比较：

1. 联合学习：按发布决定价值选择是否做下一次观察，预算用尽或无法改善决定时停止。
2. 最优静态观察：预先固定计划，执行中不根据反馈改计划。在相同预算下枚举全部固定计划，事后用隐藏标签按发布决策质量、再按真实工具操作数选择最好的计划。这是静态方法的上界。同时另报三条案例必须共用的最好固定计划。
3. 简单查表：可迁移动作类型查表加上惯例固定关系，不预绑定这三个工作流。
4. 完整追踪：固定穷尽顺序为先 `subsequent_reads`、后 `contrast_canaries`，不按发布决定价值跳过。必须同时报告（a）与联合学习相同预算上限下能完成的观察，以及（b）无预算限制时两条消费向观察都执行的结果。不得为证明低成本优势而少做消费追踪。

真实工具操作由仪器化的世界调用计数，区分为健康示范采集、额外观察、运行时验收读取。逻辑读数另栏报告，不称作真实工具操作。数字以 `cost-curve-receipt.json` 为准。不调用语言模型或 GPU。
