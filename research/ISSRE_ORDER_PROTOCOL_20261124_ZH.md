# 调用先后断言的双重冻结验证
选择从未用于本项目设计的两个状态机库 transitions 0.9.0 与 python-statemachine v2.3.0。读文档之前锁定项目无关的文本解析器、文档路径范围和候选历史提交清单。契约提取仅使用根 README 和文档目录下预定的动作、回调、生命周期、处理模型或执行顺序说明。人工对照可查同标签的公开 API 使用说明。
 
提取器支持有明确顺序提示的编号列表或表格，以及带代码标识符的直接前后句式。仅在同一小节按共享事件做传递闭包。分别报告直接边、来自不同表格行的传递边、来自不同散文条款的推导；输出任何一种不等于已成功理解跨段自然语言。事件名和测试输出都不能用于修改已锁规则。
 
在读取提取结果和补丁前，按文档写下一个普通成功外部转换的公开回调参与者、期望顺序和公开事件到运行标识的映射；版本两侧共用。允许从每项目一次转换产生整条轨迹，对照最终状态、参与者集合和先后关系。报告一阶边与间接边、可绑定比例、同一次真实调用的结果以及可用子集。观察者仅记录公开回调。离线交换相邻回调仅用于检查断言敏感性；交换结果不是历史缺陷或真实软件运行。不能把配对条件顺序直接推广到失败转换、嵌套状态或多个候选转换。
 
抽样时间窗为 2024-08 至 2025-12，在默认分支可达的非合并提交按原有功能修复关键词和运行库路径各取最近三项。所有匹配数量和缺失均披露。锁定输入、映射、契约和观察器之后，运行父提交与修复提交各一次成功事件；同轨迹比较四种观察。报告公开参考顺序的告警、历史提交的旧错新对、无法运行的提交及分母。保留新材料首次提取的完整结果。
