【E3 结果】预算×定向比例 + Calendar-only 对照（E3-A）；Database 剂量（E3-B）。Qwen3-0.6B QLoRA，A 场景，3 种子，45 个训练 + 45 次评测全部完成（fails=0）。全部从 E4 共享中点前缀出发，10% 档和 none 复用 E4。账本核对通过：同预算优化步数相同，复习 token 在预算的 99–100%。统计用层级 bootstrap，n=3 只写“方向一致”。

我的初步判断：
a) 收益不是预算的平滑递减，而是“关键子技能何时被覆盖”；
b) 工具差异明显：Python 很便宜，File 缓慢上升，DB 完全依赖 target 覆盖；
c) 净收益在 10% 左右最好，20% 有新工具代价；
d) dose_db6 在 10% 下 nat old 0.885、v3 非劣效通过，但 File 只有 0.667（b10_tf50 是 0.789）。提示“按工具缺口分配”：Python 少给，DB 给 4–6 条 target，File 保持 tf50 的量，可能优于固定 tf25/tf50。
局限：n=3；DB nat v2 与 target 模板高度对应；评测是 batch-1，受生成速度限制（每次约 200 秒）。
