六、哪些模块暂时不建议融合？
我暂时不推荐把 RAG、复杂多 Agent 协作、强化学习教师、动态 LoRA 专家扩展全部加入。
这些方法并不是没有价值，而是会改变研究重点：
• RAG 更偏向推理时检索外部知识。
• 多 Agent 增加系统复杂度，但不一定改善小模型参数中的遗忘。
• 教师–学生可以生成经验，但会引入数据质量与教师成本问题。
• 动态 LoRA 专家属于参数扩展路线，可能弱化你目前以固定模型规模、固定 Replay 预算为核心的研究故事。

瓶颈 1：不知道什么经验真正有效
目前已经知道：
• 特定 target 经验有价值；
• 普通同工具经验不一定有效；
• 近邻操作模式可能产生额外收益。
但我们不知道如何在训练之前预测这些收益。
这是最核心的科学问题。
瓶颈 2：没有充分证明跨模式迁移
例如：
filter_top 的经验能否帮助模型完成新的 filter_count？
search_first 的经验能否帮助模型完成 search_last？
目前有一些探索性现象，但缺少严格控制实验。
瓶颈 3：真正的遗忘恢复还缺少完整验证
虽然已经找到 db.list_tables 和 py.median 的真实遗忘证据，但目前 E3-B2 的主要实验对象仍是原本没有掌握的 filter_cmp_top。
因此还没有完整证明：
模型原本掌握技能 → 学习新工具后遗忘 → 自适应 Replay 重新恢复。
瓶颈 4：实验规模和评测仍然有限
• 只有一个 0.6B 模型。
• 主要是 A 场景。
• E3-B2 实验 A 目前只完成种子 08。
• Calendar v3fix 的工具选择准确率固定在约 50%，区分能力不足。
• 部分模式存在天花板或地板效应。
这些都限制了目前结论的外部有效性。

四、下一步应该怎么做？
我不建议现在马上开发复杂的梯度预测器，也不建议直接启动 E5。
建议分成三个阶段。
第一阶段：完成机制验证
最高优先级
1. 补跑 E3-B2 的种子 09、10，保持已经冻结的计划不变。
2. 比较 target_other、target_dbbg、dose_db0 和 dose_db1。
3. 确认单条 target 经验是否在三个种子上都能带来一致收益。
随后预注册近邻经验消融：
• target-only；
• near-neighbor-only；
• target + near-neighbor；
• target + generic background；
• 无 target 对照。
所有组保持相同 Token 预算、优化步数和训练起点。
第二阶段：建立真正的经验价值估计器
从前面的干预实验构建经验—技能恢复数据。

五、我建议你现在先不要做什么
1. 不要继续大规模扫描固定 Replay 比例。E3 已经提供了相当多的预算信息。
2. 不要直接把梯度相似度当作经验价值。它只是一个候选代理指标，需要验证预测能力。
3. 不要把 filter_cmp_top 的恢复称为遗忘恢复。
4. 不要过早引入多个 Agent、教师模型和复杂强化学习模块。先把核心算法做出来。
六、最终评价
我认为本轮研究有三个实质性进步：
• 从工具级遗忘推进到操作模式级能力分析。
• 从经验数量实验推进到经验身份和背景作用的机制研究。
• 从单纯观察准确率推进到有 T0/T1/T2 支撑的遗忘识别。
但当前最大的缺口依然是：
我们知道不同经验的恢复效果不一样，却还不知道如何提前预测哪条经验最值得复习。
这就是下一阶段真正的创新入口。
如果让我给你确定下一阶段的论文故事，我会选择：
Utility-Aware Continual Tool Learning
面向持续工具学习的经验价值感知与自适应重放。
核心贡献不再是简单地让模型复习，而是让小模型自己判断：
1. 我究竟忘记了什么？
2. 哪些历史经验能够恢复它？
3. 复习这些经验需要多少 Token？
4. 什么时候应该停止，避免影响其他技能？
当前阶段：实验基础已经有了，研究问题也逐渐清晰。接下来最重要的是完成 E3-B2，然后把经验价值预测做成真正的算法，而不是继续堆叠实验现象。
这才是从目前的实验研究走向 CCF B 投稿水平最关键的一步。
