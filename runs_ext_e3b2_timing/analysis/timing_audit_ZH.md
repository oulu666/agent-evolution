## 6. 解读

**(1) 剂量 S 曲线。** 在 n≥1 的 36 个 B1 点上，Σafter（0.936）和 mom（0.928）的秩相关都高于 n（0.811）；控制 Σafter 后 n 的偏秩相关是 −0.086，控制 mom 后是 −0.199；反过来控制 n 后 Σafter 仍有 0.799。描述性 logistic 里 mom + 种子的偏差 65.3，n + 种子 124.0；在 mom 之上再加 n，系数为 −0.095，偏差只降到 64.9。同暴露分箱里看得最清楚：Σafter 2–4 这一档，1 条 target 均值 0.430、2 条 0.400、3 条 0.267，条数多并没有更好。

因此，原来「S 曲线由独立 target 条数决定，1 条几乎无效，4–6 条基本恢复」的说法要改。1 条插在第 159 位只有 1 次更新，所以接近无效（0.100）；同一条挪到第 143 位就有 0.389–0.467。剂量 1→2 原来的 +0.300（0.100→0.400），几乎全部可以由暴露解释：dose_db1_pos143（1 条，Σafter 3.3）0.389，dose_db2（2 条，Σafter 3.3）0.400。剂量 2→6 那一段的上升与 Σafter 从 3.3 升到 15.7 完全同步，现有臂里条数和暴露高度共线，没有「多条但都很晚」或「少条但很早」的点，分不开。另外，只看「最后一条之后的更新次数」不够（n≥1 时 Spearman 0.075，控制它后 n 仍有 0.892），起作用的是所有 target 的总暴露。能留下来的结论是：**恢复量随 target 模式获得的更新暴露单调上升，曲线形状仍是 S 形，但横轴应写成暴露量（条数 × 之后更新次数），不是条数。** 在 B1 的剂量和位置点上，看不到「独立条数」在暴露之外还有额外作用。但 §5 的 B32 格子里两者分不开（控制 mom 后 n 0.330，控制 n 后 mom 0.105），所以「只有暴露、条数无关」目前只是 B1 剂量点上的描述，要靠一组直接把两者拆开的实验来定。

**(2) 「覆盖比预算更重要」。** 定性部分保留，而且更清楚了：没有 target 模式的复习（ctrl_cal、b05_tf00/tf25、b10_tf00）不管预算多大都在 0 附近；B32 格子里预算本身与成绩的秩相关 0.685，控制 mom 后降到 −0.033，预算只是通过「带进来多少 target 暴露」起作用。例如 b20_tf00 没有定向比例，却因为随机抽到的 target 插在第 95 / 103 位（之后 12–14 次更新）得到 B32 0.722；它的 mom 0.776 与 dose_db4（mom 0.815，B1 0.800）接近（b10 三格 B1 与 B32 相差不超过 0.02，可作粗略参照）。需要改的是「覆盖」的定义：只数「有没有 / 有几条」不够，要把插入时机算进去。论文里建议写成「复习什么、在何时复习，比复习多少更重要」，并把覆盖度量换成 target 模式的更新暴露。Calendar v3 在 20% 预算下的代价是另一件事，不受本审计影响。

**(3) 与 v2 梯度 pilot、近邻假设的关系。** tf25 高于实验 A 两臂，本轮单变量对照已经由插入位置解释（H-timing 支持）；不需要再用「近邻经验」或 target 条目身份（T-005 / T-008 vs T-001）去解释这 0.3 的差距。
